# cyclistic-bike-share-analysis



## Executive Summary
This project analyzes bike-share usage data from Cyclistic (May 2020) to uncover behavioral differences between **Annual Members** and **Casual Riders**. The strategic goal is to inform targeted marketing campaigns that convert casual riders into high-value annual members.

## Tools & Technologies Used
* **Data Processing & Feature Engineering:** Microsoft Excel
* **Data Visualization & Storytelling:** Tableau Public
* **Version Control & Portfolio Documentation:** Git & GitHub

## Key Analytical Insights
1. **Rider Composition:** Annual Members account for the majority of total trips, while Casual Riders represent the primary target for conversion.
2. **Ride Duration Differences:** Casual Riders spend nearly double the time per trip compared to Annual Members.
3. **Peak Usage Patterns:** Annual Members peak during weekday commuting rush hours (8 AM & 5 PM), whereas Casual Riders peak during weekend afternoons for leisure.

## Strategic Business Recommendations
* **Weekend & Summer Passes:** Create tailored promotional packages to transition weekend casual riders to full annual subscriptions.
* **In-App Prompts:** Trigger membership conversion offers when casual riders log long-duration rides.
